# EJN (European Journal of Neuroscience) Templates and Guidelines

## Templates Available

### 1. LaTeX Template
- **File:** `WileyDesign.zip` (downloaded from Wiley Author Services)
- **Folder:** `Optimal-Design-layout/`
- **Documentation:** `Author-guidelines for LaTex Template_Wiley (2026).pdf`

### 2. Template Features
- Standard article layout for Wiley journals
- Class, style and font files included
- Compatible with MiKTeX 2.9 (21.2) or TeXLive 2021+
- Supports BibTeX format for references

### 3. Submission via Research Exchange (ReX)

**Platform:** https://wiley.atyponrex.com/journal/EJN

**File Designations:**
- Main Document – LaTeX .tex File
- Main Document - LaTeX PDF (compiled PDF)
- LaTeX Supplementary File (supporting files)

**Required Files for LaTeX Submission:**
1. Main .tex file
2. Compiled PDF version
3. All supporting files (figures, bibliographies) in a .zip
4. References in BibTeX format (preferred)

### 4. Post-Acceptance Files Required
1. PDF created from finalized source files (no errors)
2. LaTeX source code (text, figure captions, tables - preferably single file)
3. BibTeX format files (.bib, .bbl, .bst)
4. Electronic graphics files (EPS, PDF, or TIFF)

**Note:** Do not create figures using LaTeX codes.

### 5. Key Formatting Rules

#### Free Format Submission
- Initial submission: Flexible format
- Revision stage: Must follow full author guidelines
- Submit TWO copies at revision:
  1. Clean copy
  2. Marked changes copy (without tracked changes)

#### Statistical Presentation (IMPORTANT)
- **DISCOURAGED:** Bar charts
- **RECOMMENDED:** Boxplots or scatterplots
- Must report: statistical term + degrees of freedom + precise p-value

#### Abstract
- Maximum 250 words
- Unstructured (no headings)

#### Running Title
- Less than 40 characters

### 6. Required Statements on Title Page

1. **Data Availability Statement** (Required)
2. **Funding Statement** (Required)
3. **Conflict of Interest Disclosure** (Required - or state "None")
4. **Ethics Approval Statement** (Required for human/animal studies)
5. **Patient Consent Statement** (Required if applicable)
6. **Clinical Trial Registration** (If applicable)
7. **Author Contributions** (CRediT format - Required)
8. **ORCID** (Required for all authors)

### 7. Article Type: Short Communication Specifications

If submitting as Short Communication:
- **Word limit:** 3,500 words
- **Figures:** Maximum 4
- **Tables:** Maximum 2
- **Supplementary material:** Strongly discouraged
- **Abstract:** 250 words, unstructured
